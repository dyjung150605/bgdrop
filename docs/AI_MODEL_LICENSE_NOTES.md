# AI 모델 라이선스 및 상업용 고려사항

BgDrop에서 사용 가능한 배경제거 AI 모델 선택 시 라이선스에 따른 허용 범위 정리.

## 요약

현재 BgDrop은 MIT 라이선스 모델만 사용 중 (`isnet-general-use`, `u2net`, `u2net_human_seg`).
품질이 더 높은 최신 모델(BiRefNet, BRIA RMBG)은 **CC BY-NC 4.0**이라 상업적 사용이 제한됨.

## 현재 사용 중 (MIT, 상업용 OK)

- **ISNet (isnet-general-use)** — 경계 품질 우수, MIT ✅
- **U2Net** — 범용, MIT ✅
- **U2Net Human Seg** — 포트레이트, MIT ✅

## 품질은 더 좋지만 상업용 금지 (CC BY-NC 4.0)

- **BiRefNet** — 현재 SOTA급, 가장 품질 좋음 ❌
- **BRIA RMBG 2.0** — 배경제거 특화 ❌
- **BRIA RMBG 1.4** — 동일 제약 ❌

## MIT/Apache 내 대안

- **silueta** (Apache 2.0) — rembg 내장, U2Net보다 경량. 품질은 보통
- **SAM / SAM2** (Apache 2.0) — Meta. 품질 우수하지만 **클릭/박스 프롬프트 필요** → 자동 배경제거엔 부적합
- **MODNet** (Apache 2.0) — 포트레이트 특화. 인물 사진에선 ISNet보다 나을 수 있음

## CC BY-NC 4.0 해석

### 확실히 허용

- 본인 개인 사용 ✅
- 연구, 학습, 취미 ✅
- 비영리 단체 사용 ✅

### 확실히 금지

- 모델 번들 프로그램 **판매** ❌
- 유료 SaaS/웹서비스 ❌
- 광고 수익 내는 무료 앱 (광고 = 상업) ❌

### 회색 지대 (보통 상업적으로 간주)

- 🟡 영리 기업 직원이 업무에 사용 — 회사 업무는 대개 상업 활동으로 봄
- 🟡 무료 배포지만 회사 홍보/브랜딩 목적 — 간접적 상업 이익으로 해석 가능
- 🟡 GitHub 오픈소스 공개만 — 배포자 의도는 비상업이어도, 다운로드 사용자의 용도까지 제약 불가

## BgDrop 관점에서의 결론

| 사용 시나리오 | 가능한 모델 |
|---|---|
| 본인 개인 사용만 | 전부 가능 (BiRefNet/BRIA 포함) |
| GitHub 무료 배포, 사용자에게 "비상업" 고지 | 전부 가능하되 모델별 라이선스 명시 필요 |
| 유료 판매 / 수익화 | **MIT만** (현재 구성 유지) |
| 회사 내부 도구 | **MIT만** 권장 |

## 향후 방향 옵션

1. **현재 구성 유지** — 상업 배포 안전, ISNet + Post Process + Alpha Clean + Alpha Matting 조합으로 약 90% 품질
2. **비상업 모델을 선택지로 추가** — 사용자에게 라이선스 고지 후 옵션 제공
3. **포트레이트 모드에 MODNet 실험** — MIT/Apache 범위 내 추가 가능성
